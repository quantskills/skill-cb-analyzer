# 可转债核心计算公式

## 1. 转股价值 (Conversion Value)

```
转股价值 = (100 / 转股价) × 正股收盘价
```

- 表示将转债转换为股票后的市场价值
- CV > 130 → 触发强赎条款（通常条件）

## 2. 转股溢价率 (Conversion Premium Rate)

```
溢价率 = (转债价格 − 转股价值) / 转股价值 × 100%
```

- 正值：转债价格高于转股价值（支付了期权溢价）
- 负值（折价）：存在转股套利空间
- < 20% 被认为是合理区间

## 3. 双低值 (Double-Low Value)

```
双低值 = 转债价格 + max(溢价率, 0) × 100
```

- < 120：有吸引力
- 经典的防守型可转债策略

### 与集思录公式的差异

| | 本 Skill | 集思录 (Jisilu) |
|---|---|---|
| 公式 | `价格 + max(溢价率, 0) × 100` | `价格 + 溢价率 × 100` |
| 折价券处理 | 折价部分不计入（floor at 0），双低值 = 价格 | 折价为负值，双低值 < 价格 |
| 设计理由 | 折价（负溢价）是**加分项**而非减分项。若直接用负溢价，折价券的双低值被人为压低，导致折价套利标的在排名中过度靠前，挤压真正"低价格+低溢价"的防守型标的。`max(溢价率,0)` 确保折价券的排名由价格和评分体系共同决定，不因折价而获得不公平的双低排名优势 | 折价券双低值可能极低（如价格 110 + (−10%)×100 = 100），排在双低榜前列 |

在实践中，本 Skill 的折价券会在「正股联动精选」（第 5 节）中单独呈现折价套利机会，而非通过压低双低值进入双低策略精选。

## 4. 纯债价值 (Bond Floor)

```
纯债价值 = Σ(票息_i / (1+r)^t_i) + 本金赎回价 / (1+r)^T
```

- r：基于评级的企业债折现率（AAA 1.5%, AA 2.0%, A 3.0%, 其他 4.0%）
- 表示转债作为纯债券的价值

## 5. 到期收益率 (YTM)

```
求解 r 使得：转债价格 = Σ(票息_i / (1+r)^t_i) + 期末现金流 / (1+r)^T
```

- 使用 Newton-Raphson 迭代法求解
- 现金流通胀用期末赎回价（通常 106-110 元，含末期利息）

## 6. 票息估计 (Coupon Schedule)

基于信用评级的阶梯式票息模型，模拟 A 股可转债典型票息结构：

| 评级 | 年票息序列 (6年) |
|------|-----------------|
| AAA / AA+ | 0.2%, 0.4%, 0.6%, 0.8%, 1.5%, 2.0% |
| AA / AA- | 0.3%, 0.5%, 0.8%, 1.2%, 1.5%, 1.8% |
| A+ / A | 0.5%, 0.8%, 1.0%, 1.5%, 2.0%, 2.5% |
| A- 及以下 | 0.8%, 1.0%, 1.5%, 2.0%, 2.5%, 3.0% |

- `estimate_coupon_schedule(credit_rating, total_years, remaining_years)` 实现
- 按 remaining_years 截取未来付息期
- 此为基础模型，实际票息以各券募集说明书为准

## 7. 强赎触发比

```
强赎触发比 = 正股价 / 转股价
```

- ≥ 1.30：触及强赎条款
- 1.20–1.28：预警区间
- 含连续日计数追踪：`get_consecutive_days(field="redemption_ratio", direction="above", window=30)`

## 8. 回售触发比

```
回售触发比 = 正股价 / (转股价 × 0.70)
```

- < 1.0：股价低于回售触发价
- 含连续日计数追踪：`get_consecutive_days(field="putback_ratio", direction="below", window=30)`

## 9. Delta (弹性指标)

### 主公式：Black-Scholes Delta（v1.4+）

```
BS Delta = N(d1)

其中：
  d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T)
  S  = 正股收盘价
  K  = 转股价
  T  = 剩余期限（年）
  r  = 无风险利率 (config["options"]["risk_free_rate"], 默认 0.025)
  σ  = 历史波动率 HV (年化)

N(d1) ∈ (0, 1)，始终有效
```

- Delta > 0.70：高股性，紧密跟随正股
- Delta < 0.30：偏债性，跟涨能力弱
- 中间值：平衡型，兼具股性和债性

### 降级路径

当 HV 无法计算时（如历史数据不足 60 个交易日），BS Delta 不可用，降级使用近似弹性：

```
近似 Delta = 转股价值 / 转债价格    (仅作为 BS Delta 不可用时的备选)
```

- BS Delta 可用时**始终优先使用 BS Delta**
- 近似 Delta 与 BS Delta 数值差异通常 < 0.05（平价附近）到 0.15（深度实值/虚值）
- BS Delta 无法计算时，`Delta弹性` 检测器回退到近似 Delta 并标注 `delta_source: "approximate"`，BS Delta 标注 `delta_source: "black_scholes"`

> **历史说明：** v1.3 及之前版本仅使用 `转股价值 / 转债价格` 近似公式。v1.4 起引入 Black-Scholes 模型，近似公式保留为备选降级路径。

## 10. 正股动量 (Stock Momentum)

```
20日收益率 = (Close_t − Close_{t-20}) / Close_{t-20} × 100%
均线多头排列: MA5 > MA10 > MA20
均线空头排列: MA5 < MA10 < MA20
```

- 分母（Close_{t-20}）为零或非有限值时，返回中性信号
- 正收益 + 多头排列 → 看涨信号
- 负收益 + 空头排列 → 看跌信号

## 11. 溢价率历史分位 (Premium Percentile)

```
分位 = (历史溢价率低于当前值的天数) / 总历史天数
```

- 基于 HistoryStore 存储的逐券 premium_rate 时序
- 窗口：可配置 `premium_percentile_window`（默认 60 个交易日）

## 边缘情况处理

以下边缘情况在所有检测器中统一处理，确保不因单券异常而阻塞全流程。

### 通用边界

| 情况 | 处理方式 | 影响检测器 |
|------|----------|-----------|
| 转债价格为 0 或负值 | 跳过该券，记录 WARNING 日志 | 全部 |
| 正股价格为 0 或负值 | 跳过 C 组联动信号，A/B/D 组继续 | C1-C4, BS Greeks |
| 转股价缺失或为 0 | 跳过转股价值/溢价率/强赎相关信号 | A1, A4, B1, B3, C1, Delta |
| 到期日缺失 | YTM 和纯债价值无法计算，跳过 A2/A3 | A2, A3, B4 |
| 评级缺失 | 默认使用 A 级折现率 (3.0%) + A 级票息序列 | A2, A3, D3 |
| K线数据 < 20 日 | 跳过均线排列 + 20 日收益率，`正股动量` 返回中性 | C1, C4 |
| K线数据 < 60 日 | HV 无法计算，BS Greeks 降级为近似 Delta | C3, BS, IV |
| 历史时序 < 窗口下限 (默认 2 条) | 分位/连续日返回哨兵值 (−1)，标记为「数据不足」 | A4, B1, B3, D2 |
| **ST / \*ST / PT / 退市正股** | **v1.7+：直接排除全券**（2026-07-06 起 ST 涨跌幅 ±5%→±10%，正股波动翻倍，转债信用风险显著放大，不再使用惩罚分） | 全部检测器跳过 |

### 2026-07-06 新规影响：ST 涨跌幅放宽

2026年7月6日起，沪深主板 ST / \*ST 股票涨跌幅限制由 **±5% → ±10%**（与主板普通股统一）。
对本 Skill 的影响：

| 影响维度 | 说明 | 处理 |
|----------|------|------|
| **信用风险排序** | ST 正股波动翻倍，转债下行风险显著放大 | 直接排除，不再使用 -20 惩罚 |
| **Delta 弹性** | ST 正股波动率上升，BS Delta 跳变加剧 | 排除后不适用 |
| **波动率信号** | HV/IV 在 ST 正股上更不稳定 | 排除后不适用 |
| **下修博弈** | ST 公司下修空间和意愿可能变化 | 排除后不参与下修评分 |
| **历史回测** | 旧数据中 ST 转债在 ±5% 环境下的表现不代表新环境 | 回测时标注 ST 新旧制度分界线 (2026-07-06) |

### 公式特化边界

| 公式 | 情况 | 处理方式 |
|------|------|----------|
| **YTM (Newton-Raphson)** | 迭代 100 次未收敛（\|f(r)\| > 1e-6） | 返回 `NaN`，`YTM防御` 检测器跳过该券，标注 `ytm_source: "convergence_failed"` |
| **YTM** | 初始猜测 r₀ 导致 f(r₀) 无界 | 回退到 r₀ = 0.05（5%），重试迭代 |
| **纯债价值** | 折现率 ≤ 0 | 使用 floor 0.001 (0.1%) |
| **双低值** | 溢价率为负（折价） | `max(溢价率, 0)` → 折价部分 floor at 0，不压低双低值 |
| **双低值** | 转债价格 ≥ 200 | 双低值必然 ≥ 200，不推荐但正常计算 |
| **BS Delta** | HV < 0.01（几乎零波动） | 使用 floor HV = 0.01 防除零，标注 `hv_floored: true` |
| **BS Delta** | T < 0.02 年（< 5 个交易日到期） | 使用 floor T = 0.02，避免极短期权定价失真 |
| **隐含波动率 (IV)** | 二分法 200 次未收敛 | 返回 `NaN`，`IV分位` 检测器退出，标注 `iv_source: "failed"` |
| **IV** | 期权价值 ≤ 内在价值（无时间价值） | IV 不可解（套利边界），返回 0，标注 `iv_source: "no_time_value"` |
| **溢价率历史分位** | 样本量 < 10 | 返回哨兵 −1，`溢价率分位` 检测器不触发 |
| **强赎连续日计数** | HistoryStore 中无可查历史 | `get_consecutive_days()` 返回 0，从当前日开始计数 |
| **正股动量 20 日收益** | Close_{t-20} 为 0 或 inf | 返回 0.0（中性），`正股动量` 不触发 |
| **credit_rating 空字符串** | 评级字段为空 | 降级为 `A` 级默认值，标注 `rating_defaulted: true` |

### 降级链行为

```
数据获取失败 (单券) → skip_stock() → 该券所有信号 = 0
                       → 计数器 skipped_count += 1
                       → 日志记录 bond_code + 失败原因
                       → 报告「数据溯源」节显示 skipped_count

配置校验失败 (启动时) → 28 规则逐条检查
                       → 非阻塞 WARNING 日志
                       → 使用 config.json 默认值继续
```
